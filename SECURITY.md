# Security Policy

Please report a suspected vulnerability privately through GitHub's security
advisory flow for `sonicfieldlabs/listening-stack` when available. Do not open a
public issue containing an exploit, credential, private recording, local path,
host configuration, or model token.

Include the installer version, operating system, Python version, exact command,
and a minimal redacted reproduction. Replace usernames, home paths, hostnames,
addresses, tokens, and audio content before sharing logs.

The public-alpha release receives security fixes on the current `main` branch
and latest release line. Older executable assets may not receive backports.
